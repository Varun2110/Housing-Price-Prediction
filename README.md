# Housing-Price-Prediction
Machine Learning model to predict California housing prices using Random Forest Regressor. Built with Python, Scikit-learn, Pandas, and Matplotlib.


I built this project to understand how machine learning works on real-world data. The California housing dataset has features like income, location, and number of rooms — I wanted to see which of these actually matters when predicting house prices. Turns out, median income is a bigger factor than I expected. The Random Forest model gave me an R² of 0.81, which I'm fairly happy with for a first attempt.
